계정 및 데이터 삭제

시행일: 2026년 8월 22일 · English

이 페이지는 DailySmile Studio가 운영하는 행웃아웃행의 계정 및 데이터 삭제 방법을 안내합니다. 행웃아웃행 계정을 삭제해도 사용자의 Google 계정 자체는 삭제되지 않습니다.

앱에서 바로 회원 탈퇴

앱의 설정 > 계정 관리 > 회원 탈퇴를 누르고 현재 로그인된 Google 계정으로 본인 확인을 완료하면 계정 및 서버 데이터 삭제가 시작됩니다. 현재 기기의 앱 전용 웃음 기록, 사진, GIF와 설정도 함께 삭제됩니다.

앱을 사용할 수 없는 경우

앱을 삭제했거나 로그인할 수 없다면 아래 이메일로 계정 삭제를 요청해주세요. 행웃아웃행에 로그인했던 Google 이메일을 함께 적어주시면 본인 확인 후 처리합니다.

dailysmile.help@gmail.com

삭제되는 데이터

  • 행웃아웃행 Firebase 인증 계정과 사용자 식별자
  • 닉네임, 초대코드
  • 친구 목록, 친구 요청 상태
  • 친구 활동 알림 토큰, 플랫폼, 알림 언어 코드 및 알림 사용 설정
  • 사용자가 친구에게 붙인 개인 이름
  • 웃은 날짜, 누적 점수와 콤보, 웃음 점수 공개 여부
  • 공개 리그 표시에 필요한 점수 정보
  • 친구별 일일 웃기기 사용 상태와 광고 세션·거래 기록
  • 만 14세 이상 확인, 사진 전송 이용규칙·반응 분석 동의 기록
  • 차단 목록과 계정에 연결된 짧은 반복 호출 제한 기록
  • 보관 기간이 남아 있는 친구 기능 사진 데이터

기기와 외부 앱에 남을 수 있는 데이터

앱 안에서 회원 탈퇴하면 현재 기기의 앱 전용 데이터도 함께 삭제합니다. 다만 휴대폰 사진 앱에 별도로 저장한 GIF, 다른 앱으로 공유한 파일, 다른 오프라인 기기에 남아 있는 로컬 파일은 원격으로 삭제할 수 없습니다. 이메일을 통한 외부 삭제 요청도 기기 안의 로컬 파일을 원격으로 삭제하지는 못합니다.

처리 기간

앱 안의 회원 탈퇴는 본인 확인 후 즉시 삭제 절차를 시작합니다. 이메일을 통한 외부 요청은 본인 확인 후 보통 30일 이내 처리합니다. 법령 준수, 보안, 부정 이용 방지와 같이 필요한 경우 일부 기록은 필요한 기간 동안 제한적으로 보관될 수 있습니다.
