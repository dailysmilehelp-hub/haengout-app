계정 및 데이터 삭제 요청

시행일: 2026년 7월 27일

이 페이지는 DailySmile Studio가 운영하는 행웃아웃행의 계정 및 데이터 삭제 요청 방법을 안내합니다. 앱 안에서는 설정 > 계정 관리 > 계정 삭제 요청하기를 통해 같은 요청을 보낼 수 있습니다.

삭제 요청 방법

아래 이메일로 계정 삭제를 요청해주세요. 앱에서 로그인한 Google 이메일을 함께 적어주시면 더 빠르게 확인할 수 있습니다.

dailysmile.help@gmail.com

삭제되는 데이터

  • Google 로그인 계정과 연결된 Firebase 사용자 식별자
  • 닉네임, 초대코드
  • 친구 목록, 친구 요청 상태
  • 친구 활동 알림 토큰 및 알림 사용 설정
  • 사용자가 친구에게 붙인 개인 이름
  • 웃은 날짜, 누적 점수와 콤보, 웃음 점수 공개 여부
  • 공개 리그 표시에 필요한 점수 정보
  • 보관 기간이 남아 있는 친구 기능 사진 데이터

기기 안에 남을 수 있는 데이터

개인 웃음 기록 사진, GIF, 로컬 웃음 기록은 기본적으로 사용자의 기기 안에 저장됩니다. 앱을 삭제하거나 앱 안에서 기록을 삭제하면 기기 데이터가 함께 삭제될 수 있습니다. 서버 삭제 요청은 기기 안의 로컬 파일을 원격으로 삭제하지는 못합니다.

처리 기간

삭제 요청을 확인한 뒤 보통 30일 이내 처리합니다. 법령 준수, 보안, 부정 이용 방지와 같이 필요한 경우 일부 기록은 필요한 기간 동안 제한적으로 보관될 수 있습니다.
