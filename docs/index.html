개인정보 처리방침

시행일: 2026년 7월 29일

DailySmile Studio는 "행웃아웃행"을 운영하며, 사용자의 개인정보와 사진 데이터를 안전하게 다루기 위해 이 개인정보 처리방침을 제공합니다.

1. 처리하는 정보

  • Google 로그인 정보: Firebase Authentication 사용자 UID, 이메일 주소, 표시 이름
  • 친구 기능 정보: 닉네임, 초대코드, 친구 목록, 사용자가 친구에게 붙인 개인 이름, 친구 요청 상태, 친구 활동 알림 설정
  • 웃음 점수 공개 정보: 웃음 점수 공개 여부, 공개 리그 표시에 필요한 웃음 기록 점수
  • 알림 정보: 친구 활동 알림을 켠 경우 기기 푸시 토큰, 플랫폼, 알림 사용 여부
  • 웃음 기록 정보: 촬영 날짜, 웃음 감지 결과, 웃음 확률, 얼굴 감지 수, 웃은 날짜, 날짜별 점수, 콤보 정보
  • 사진 정보: 오늘의 웃음 사진, 친구에게 보내는 웃긴 사진, 사용자가 전송에 동의한 반응 사진

앱은 위치 정보, 연락처, 결제 정보, 건강 정보, 마이크 음성 데이터를 수집하지 않습니다.

2. 사진 처리 방식

개인 웃음 기록 사진과 GIF는 기본적으로 사용자의 기기 안에만 저장됩니다. Google 로그인 추가 후에도 개인 웃음 사진 원본과 GIF는 서버에 자동 백업하지 않습니다.

같은 Google 계정으로 다른 기기에서 로그인했을 때 누적 점수와 콤보를 이어가기 위해 웃은 날짜와 점수 요약 정보는 서버에 저장될 수 있습니다. 이 기록에는 개인 웃음 사진 원본이나 기기 안의 사진 파일 경로가 포함되지 않습니다.

얼굴 감지와 웃음 판별은 앱 기능 제공을 위해 사용자의 기기 안에서 처리되며, 사용자의 신원을 확인하거나 개인을 식별하기 위한 생체인식 목적으로 사용하지 않습니다. 웃음 확률과 얼굴 감지 수는 개인 웃음 기록을 보여주기 위한 정보로 사용됩니다.

친구에게 보내는 웃긴 사진과 사용자가 전송을 선택한 반응 사진만 Firebase Storage에 저장될 수 있으며, 관련된 송신자와 수신자만 접근할 수 있도록 제한합니다. 해당 사진은 업로드 후 7일이 지나면 자동 삭제 대상으로 처리됩니다.

3. 이용 목적

  • Google 계정 기반 로그인 및 사용자 식별
  • 앱 삭제 또는 새 기기 로그인 후 친구 관리 정보, 친구 활동 알림 설정, 누적 점수와 콤보 복구
  • 닉네임, 초대코드, 친구 목록, 친구 요청 기능 제공
  • 친구 리그와 웃음 점수 공개 기능 제공
  • 친구 활동 알림 전송
  • 웃긴 사진 보내기와 반응 결과 알림 제공
  • 오류 대응, 보안 유지, 부정 이용 방지

4. 서버 저장 범위

서버 저장 범위는 Google 로그인 계정 정보, 닉네임, 초대코드, 친구 목록과 사용자가 붙인 개인 이름, 친구 요청, 친구 활동 알림 설정과 기기별 푸시 토큰, 웃음 점수 공개 여부, 웃은 날짜, 누적 점수와 콤보, 공개 리그 표시에 필요한 점수 정보로 제한합니다. 개인 웃음 기록 사진 원본, GIF, 사진 파일 경로, 기기에 예약된 오늘의 웃음 알람은 서버에 자동 저장하지 않습니다.

5. 제3자 서비스

앱은 인증, 데이터 저장, 알림 전송을 위해 Google Firebase 서비스를 사용합니다. 사용자가 공유 기능을 직접 실행하는 경우 선택한 외부 앱 또는 서비스의 개인정보 처리방침이 적용됩니다.

6. 보관 및 삭제

서버에 저장된 계정 기반 정보는 사용자가 회원 탈퇴하거나 계정 삭제를 요청할 때까지 보관됩니다. 앱의 설정 > 계정 관리 > 회원 탈퇴에서 본인 확인을 완료하면 행웃아웃행 Firebase 인증 계정과 연결된 닉네임, 초대코드, 친구 관계와 친구 요청, 친구 활동 알림 설정과 푸시 토큰, 웃은 날짜, 누적 점수와 콤보, 점수 공개 설정, 보관 중인 친구 기능 사진을 삭제합니다. 사용자의 Google 계정 자체는 삭제하지 않습니다.

앱에서 회원 탈퇴하면 현재 기기의 앱 전용 웃음 기록, 개인 웃음 사진, 생성된 GIF와 앱 설정도 함께 삭제합니다. 휴대폰 사진 앱에 별도로 저장했거나 다른 앱으로 공유한 파일, 다른 오프라인 기기의 로컬 파일은 원격으로 삭제할 수 없습니다.

앱을 사용할 수 없는 경우 아래 페이지를 통해 삭제를 요청할 수 있으며, 본인 확인 후 보통 30일 이내 처리합니다.

계정 및 데이터 삭제: data-deletion.html

7. 보안

DailySmile Studio는 Firebase Authentication, Firestore Security Rules, Storage Security Rules를 사용해 사용자 데이터 접근을 제한합니다. Google 로그인 체계에서는 익명 로그인 사용자의 서버 쓰기를 차단합니다.

8. 아동 개인정보

행웃아웃행은 만 13세 미만 아동을 주요 대상으로 하지 않습니다. 만 13세 미만 사용자의 개인정보가 수집되었다고 판단되는 경우 보호자는 이메일로 삭제를 요청할 수 있습니다.

9. 처리방침 변경

기능, 법령, 운영 방식이 변경되면 이 개인정보 처리방침도 수정될 수 있습니다. 중요한 변경이 있는 경우 앱 또는 배포 페이지를 통해 안내합니다.
