## 수집 또는 처리하는 데이터

### 개인 정보

- 항목: 이메일 주소, 사용자 ID, 표시 이름
- 용도: 계정 관리, 앱 기능, 친구 관리, 보안/부정 이용 방지
- 처리 방식: Firebase Authentication 및 Firestore 저장
- 필수 여부: Google 로그인을 통한 앱 사용에 필요
- 제3자 제공: 광고나 판매 목적 제공 없음

### 사진 및 동영상

- 항목: 카메라 촬영 또는 사용자가 선택한 이미지
- 용도: 오늘의 웃음 사진 기록, 웃음 감지, 친구에게 웃긴 사진 전송, 사용자가 동의한 반응 사진 전송
- 서버 전송 여부:
  - 개인 웃음 기록 사진과 GIF는 서버에 자동 백업하지 않음
  - 얼굴 감지와 웃음 판별은 기기 내에서 처리하며 생체식별 또는 본인확인 목적으로 사용하지 않음
  - 친구에게 보내는 웃긴 사진과 사용자가 전송을 선택한 반응 사진만 Firebase Storage에 저장될 수 있음
- 보관: 친구 기능 사진은 업로드 후 7일 뒤 자동 삭제 대상
- 선택 여부: 친구 기능 사진 전송과 반응 사진 전송은 사용자 선택

### 앱 활동 또는 앱 정보

- 항목: 웃음 기록 날짜, 웃음 감지 결과, 웃음 확률, 콤보/점수 정보, 친구 요청 상태
- 용도: 기록 표시, 새 기기에서 누적 점수와 콤보 복원, 리그 점수 계산, 친구 기능 제공
- 서버 저장 여부:
  - 개인 웃음 기록 사진 원본, GIF, 사진 파일 경로는 로컬 저장
  - 웃은 날짜와 점수 요약, 공개 리그 표시와 친구 기능에 필요한 점수/상태 정보는 Firestore 저장
- 처리 범위: 서버의 웃은 날짜 기록에는 사진 원본, 웃음 확률, 얼굴 감지 수를 포함하지 않음

### 기기 또는 기타 ID

- 항목: 친구 활동 알림 사용 설정, 알림을 켠 기기의 푸시 토큰과 플랫폼
- 용도: 친구 요청, 웃긴 사진 전송, 반응 결과 알림
- 서버 저장 여부: Firestore 저장
- 선택 여부: 사용자가 친구 활동 알림을 켠 경우에만 처리

## 보안

- Firebase Authentication으로 사용자를 식별한다.
- Firestore/Storage Security Rules에서 `request.auth.uid` 기준으로 접근을 제한한다.
- Google 로그인 전환 후 익명 로그인 provider의 서버 쓰기는 차단한다.
- 회원 탈퇴 전 동일한 Google 계정으로 다시 인증하며, 최근 인증된 UID만 서버 삭제 함수를 호출할 수 있다.
- 서버 삭제 함수는 본인 UID에 연결된 데이터와 양쪽에 복제된 친구·도전 데이터를 삭제한 뒤 Firebase 인증 계정을 마지막에 삭제한다.
- Firebase 서비스 통신은 HTTPS 기반으로 처리된다.

- Google 계정: 행웃아웃행 회원 탈퇴로 사용자의 Google 계정 자체는 삭제하지 않음
