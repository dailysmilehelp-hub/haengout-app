# 데이터 취급 점검 기록

점검일: 2026년 7월 29일

이 문서는 현재 앱 코드의 실제 데이터 처리 방식과 개인정보처리방침, Play Console 데이터 보안 초안이 일치하는지 확인하기 위한 내부 체크리스트입니다. 기능이 추가되거나 바뀌면 이 문서와 개인정보처리방침을 함께 다시 확인합니다.

## 현재 앱 데이터 처리 요약

| 기능 | 실제 저장/전송 위치 | 현재 처리방침 반영 |
| --- | --- | --- |
| 오늘의 웃음 사진 | 기기 내부 파일 저장소, SQLite 기록 | 반영됨 |
| 웃음 판별 결과 | 기기 내부 SQLite, 친구 도전 결과 일부는 Firestore | 반영됨 |
| 얼굴/웃음 판별 | 기기 내 판별, 생체식별/본인확인 목적 아님 | 반영됨 |
| 친구 프로필 | 기기 내부 SQLite, Firebase Firestore | 반영됨 |

| 사용자가 친구에게 붙인 개인 이름 | 기기 내부 SQLite, 본인 전용 Firebase Firestore 친구 문서 | 반영됨 |
| 친구 요청 | Firebase Firestore | 반영됨 |

| 친구에게 보내는 웃긴 사진 | Firebase Storage `funny-challenges`, 업로드 후 7일 자동 삭제 | 반영됨 |
| 웃긴 사진 반응 결과 | Firebase Firestore | 반영됨 |

| GIF 생성 파일 | 기기 내부 파일 저장소, 사용자가 직접 저장/공유 | 반영됨 |
| 알림 시간/범위 설정 | 기기 내부 SQLite | 반영됨 |
| 친구 활동 알림 설정/푸시 토큰 | 기기 내부 SQLite, Firebase Firestore | 반영됨 |
| 웃은 날짜와 누적 점수/콤보 요약 | 기기 내부 SQLite, 계정 복원을 위한 Firebase Firestore `smileDays` 및 사용자 문서 | 반영됨 |
| Google 로그인 UID/이메일/표시 이름 | Firebase Authentication, Firestore 문서 식별에 사용 | 반영됨 |
| 회원 탈퇴 | 최근 Google 재인증 후 Cloud Function에서 Firebase Auth, Firestore, Storage 데이터를 삭제하고 현재 기기 로컬 데이터 정리 | 반영됨 |
| 위치, 연락처, 결제, 건강, 마이크 음성 | 현재 사용하지 않음 | 반영됨 |

## 보안 점검

- Android 배포 APK에서 `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, `SYSTEM_ALERT_WINDOW`, `RECORD_AUDIO` 권한은 제거 대상으로 설정되어 있습니다.
- 앱은 카메라, 알림, 인터넷 권한을 사용합니다.
- 친구 기능과 계정 복원 데이터는 Google 로그인 후 Firebase UID를 기준으로 Firestore/Storage 보안 규칙에서 접근을 제한합니다.
- Firebase Storage의 웃긴 사진 및 반응 사진은 송신자와 수신자만 읽을 수 있도록 제한되어 있습니다.
- 웃긴 사진과 사용자가 전송에 동의한 반응 사진은 저장소 수명 주기 정책에 따라 업로드 후 7일이 지나면 자동 삭제 대상으로 처리되며, 소프트 삭제는 사용하지 않습니다.
- 개인 웃음 기록 사진은 기본적으로 Firebase에 자동 업로드하지 않습니다.
- 계정 복원용 웃은 날짜 문서에는 사진 원본, 사진 경로, 웃음 확률, 얼굴 감지 수를 저장하지 않습니다.
- 초대코드는 기존 소유자만 갱신하거나 삭제할 수 있도록 제한합니다.
- 푸시 토큰은 사용자가 친구 활동 알림을 켠 경우에만 저장되며 본인만 클라이언트에서 접근할 수 있습니다.
- 회원 탈퇴 함수는 인증된 본인의 UID만 처리하며, 10분 이내의 최근 Google 재인증을 요구합니다.
- 탈퇴 시 양쪽 사용자 영역에 복제된 친구 관계, 친구 요청, 웃기기 도전과 결과 문서 및 관련 Storage 사진을 함께 삭제합니다.
- 인증 계정은 서버 데이터 삭제가 성공한 마지막 단계에서 삭제하여 중간 실패 시 사용자가 다시 시도할 수 있게 합니다.
- 현재 기기에서는 앱 전용 SQLite 데이터, 예약 알림, 앱 전용 웃음 사진과 GIF를 삭제합니다. 사진 앱에 내보낸 파일과 외부 공유본은 앱이 원격 삭제하지 않습니다.

## 기능 변경 시 처리방침 업데이트가 필요한 경우

다음 작업을 할 때는 사용자에게 먼저 알리고, `docs/privacy-policy.md`, `docs/index.html`, `docs/play-store-data-safety-draft.md`를 업데이트해야 합니다.

- 개인 웃음 사진을 서버나 클라우드에 백업하는 기능 추가
- 친구가 아닌 사용자에게 사진이나 점수를 공개하는 기능 추가
- SNS 로그인, Google/Apple/Kakao 로그인 등 계정 연동 추가
- 연락처 접근, 위치 기반 알림, 주소록 친구 찾기 추가
- 광고, 앱 내 결제, 구독, 후원, 유료 기능 추가
- 분석 도구, 크래시 리포팅, 광고 SDK, 푸시 마케팅 SDK 추가
- 사용자의 기기 갤러리 전체 접근 또는 사진/동영상 권한 범위 확대
- 마이크, 음성, 동영상 촬영, 건강 정보 등 새로운 민감 데이터 처리 추가
- 데이터 삭제 방식, 보관 기간, Firebase 저장 구조 변경
- 만 13세 미만 아동을 대상으로 하는 기능 또는 문구 추가

## 현재 결론

현재 앱의 데이터 취급 방식은 개인정보처리방침 및 Play Console 데이터 보안 초안과 일치합니다. 2026년 7월 29일 점검에서 앱 내 직접 회원 탈퇴, 서버 연동 데이터 일괄 삭제, 현재 기기 앱 전용 데이터 정리와 외부 삭제 요청 경로를 반영했습니다.
